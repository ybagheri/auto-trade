# فهرست آثار قابل ردیابی

این پروژه فایل‌های محلی و سوابق معاملاتی معمول MT5 ایجاد می‌کند. هدف آن پنهان‌کردن اتوماسیون نیست و برای ثبت سفارش از `OrderSend` یا برنامه‌ی MQL5 استفاده نمی‌کند.

## آثار محلی

| اثر | محل | کاربرد |
| --- | --- | --- |
| فایل سیگنال | `signals\*.json` | درخواست‌های محلی در انتظار |
| لاگ حسابرسی | `logs\audit.log` | انتقال وضعیت‌ها، ردها و نتایج |
| دفتر اجرا | `logs\idempotency.json` | جلوگیری از اجرای تکراری پس از restart |
| sentinel توقف اضطراری | `logs\KILL_SWITCH` | kill switch پایدار |
| تنظیمات محلی | `.env` | مسیرها و تنظیمات ایمنی |

این فایل‌ها محلی هستند و توسط این پروژه به شبکه ارسال نمی‌شوند.

## سوابق قابل مشاهده توسط broker

سفارش ثبت‌شده از طریق رابط دسکتاپ، سوابق معمول MT5 شامل نماد، جهت، حجم، زمان و قیمت را ایجاد می‌کند. برنامه‌ی MQL5 یا `OrderSend` در این پروژه وجود ندارد.

## ناشناخته‌ها

اینکه broker یا provider چگونه سفارش‌های ثبت‌شده از ترمینال را تفکیک می‌کند و آیا استفاده از اتوماسیون در شرایط حساب مجاز است، از سمت کلاینت قابل تشخیص نیست. کاربر باید مجاز بودن را با broker، prop firm یا account provider تأیید کند.

## موضع انطباق

این پروژه ادعا نمی‌کند اتوماسیون دسکتاپ «معامله دستی» است و ادعایی درباره مجاز یا غیرمجاز بودن این معماری نزد هر provider ندارد.
