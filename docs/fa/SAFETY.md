# Persian Safety Summary

## کنترل‌های فعلی

- dry-run به‌صورت پیش‌فرض فعال است.
- آداپتور واقعی MT5 در این مرحله مسدود است.
- kill switch، فهرست نمادهای مجاز، سقف حجم، انقضا، نرخ و سیگنال تکراری بررسی می‌شوند.
- کلیک UI معادل موفقیت یا پذیرش کارگزار نیست.
- هیچ endpoint شبکه‌ای نمی‌تواند سفارشی ثبت، تغییر یا ببندد. نه داشبورد و نه [API محلی](API.md) چنین endpointی ندارد، و API محلی مسیری را که این کار را می‌کرد با دلیلی که CLI را نام می‌برد رد می‌کند.
- [API محلی](API.md) به توکن روی هر مسیر نیاز دارد، شامل خواندن‌ها، و توکن را در رشته‌ی پرس‌وجو رد می‌کند. فقط روی لوپ‌بک bind می‌شود.
- `id` هر سیگنال پیش از استفاده به‌عنوان نام فایل اعتبارسنجی می‌شود، و اگر مسیر سیگنال خارج از پوشه‌ی سیگنال resolve شود رد می‌شود. [بازبینی امنیتی](SECURITY_REVIEW.md)
- اجرای زنده وقتی رد می‌شود که فایلی که آن را فعال کرده، فایل بازبینی‌شده‌ی checkout پروژه نباشد. تنظیم متغیر در shell همچنان کار می‌کند.
- `diagnostics` گزارش می‌دهد که تنظیمات از کدام فایل env آمده‌اند و آیا یک انسان آن را انتخاب کرده است.
- در ابهام، اجرا باید متوقف شود و retry خودکار ممنوع است.

کاربران مسئول مجاز بودن معاملات خودکار و اتوماسیون دسکتاپ نزد بروکر، پراپ‌فرم و ارائه‌دهنده حساب هستند.
