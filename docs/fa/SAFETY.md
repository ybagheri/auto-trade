# Persian Safety Summary

## کنترل‌های فعلی

- dry-run به‌صورت پیش‌فرض فعال است.
- آداپتور واقعی MT5 در این مرحله مسدود است.
- kill switch، فهرست نمادهای مجاز، سقف حجم، انقضا، نرخ و سیگنال تکراری بررسی می‌شوند.
- کلیک UI معادل موفقیت یا پذیرش کارگزار نیست.
- در ابهام، اجرا باید متوقف شود و retry خودکار ممنوع است.

کاربران مسئول مجاز بودن معاملات خودکار و اتوماسیون دسکتاپ نزد بروکر، پراپ‌فرم و ارائه‌دهنده حساب هستند.
