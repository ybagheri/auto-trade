# Compliance

Users are responsible for ensuring that automated trading, desktop automation, external trade execution, and any connected signal source are permitted by their broker, prop firm, account provider, and applicable terms.

This project is a general-purpose desktop automation and trading-execution research project. It does not claim that desktop automation is automatically considered “manual trading” merely because it does not use an Expert Advisor. It does not claim that any particular prop firm, broker, or platform permits or forbids this architecture.

Users remain responsible for account permissions, local access control, signal-source authorization, record keeping, applicable law, and broker terms. Do not expose an unauthenticated execution API to the public internet. Use only demo accounts for development testing unless the account provider and applicable terms have been independently reviewed.
